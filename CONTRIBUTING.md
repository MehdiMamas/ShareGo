# Contributing

Contributions are welcome. The setup, the checks to run before a pull request, and the project's rules are in [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

Short version:

```bash
flutter pub get
flutter analyze
flutter test
```

Look for issues labelled [good first issue](https://github.com/MehdiMamas/ShareGo/labels/good%20first%20issue). Report vulnerabilities privately; see [SECURITY.md](SECURITY.md).
