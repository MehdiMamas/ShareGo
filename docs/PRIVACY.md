# Privacy policy

ShareGo, by Mehdi Mamas. Last updated October 11, 2026.

ShareGo does not collect, store, or share any personal data.

- There is no account, sign-in, analytics, advertising, or crash reporting.
- ShareGo has no server. Text goes straight from one device to the other over your local network, encrypted on the sending device.
- On Windows, macOS, and Linux, ShareGo asks GitHub for the latest release when it starts and every 6 hours, and downloads an update from GitHub when you choose to install one. GitHub sees your IP address and the ShareGo version, as with any download. Nothing else is sent. GitHub's own privacy statement applies to these requests. The iPhone, iPad, and Android apps do not do this.
- Messages and keys are kept in memory only, and are wiped when the session ends. Nothing is written to disk.
- The camera is used only to scan the QR code on the other device. No images are saved or sent.
- Local network access is used only to find and connect to the other device.
- The device name is sent to the other device so you can see who is connecting. It is not sent anywhere else.

The source code is public at [github.com/MehdiMamas/ShareGo](https://github.com/MehdiMamas/ShareGo).

Questions: open an issue at [github.com/MehdiMamas/ShareGo/issues](https://github.com/MehdiMamas/ShareGo/issues).
